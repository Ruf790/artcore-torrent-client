# ArtCore Client

Торрент-клиент под Windows.
Python + libtorrent-rasterbar + Qt (PySide6).

## Возможности
- дизайн в стиле сайта: палитра Bootstrap 5.3, Oswald, KPI-плитки, pill-фильтры, мягкие бейджи
- оформление на выбор: «Цветное» (по умолчанию), «Яркое» с градиентами, «Сдержанное» серое
- иконки по типу содержимого (видео, музыка, образы, архивы, книги…), дерево папок на вкладке «Файлы»
- светлая / тёмная тема (или «как в Windows»), тёмный заголовок окна в тёмной теме
- .torrent и magnet: кнопками, перетаскиванием (в том числе папки с торрентами и ссылки из браузера — .torrent скачивается сам), Ctrl+V, двойным кликом в Проводнике, из браузера
- горячие клавиши для всех действий (список — Ctrl+/ или кнопка в «О программе»)
- компактный вид списка (Ctrl+Shift+L или кнопка у поиска): низкие строки — больше торрентов на экране
- окно добавления: папка из выпадающего списка (по умолчанию, категории, недавние, папки торрентов) или своя, выбор файлов (дерево с галочками), «на паузе», свободное место на диске
- вкладка «Файлы»: прогресс каждого файла, приоритет «Высокий / Обычный / Не качать» (правый клик)
- свойства торрента (правый клик → «Свойства…»): свои лимиты скорости, супер-сид, правило остановки раздачи
- остановка раздачи при рейтинге N или через X часов: общая в настройках, своя для торрента или «не останавливать»
- вкладка «Скорость»: график загрузки и отдачи за 5 / 30 / 60 минут
- карта кусков на вкладке «Общее»
- расписание скорости: в заданные часы свои лимиты (окно может переходить через полночь)
- вкладка «Статистика» (как в BitComet): версия, время работы, локальный/внешний IP, открыт ли порт,
  UPnP/NAT-PMP, брандмауэр, DHT, скорость и лимиты, память/CPU, скачано и отдано за всё время
- вкладка «Журнал»: № / время / тип / сообщение, цвет по типу (система, сеть, торрент, трекер, ошибка),
  фильтр, копирование; passkey в сообщениях трекеров скрыт
- категории со своими папками: выбор в окне добавления, колонка, фильтр, правый клик → «Категория»
- следящая папка: .torrent из неё добавляются сами (с выбранной категорией), файл переименовывается в .torrent.added
- перенос готовых загрузок в другую папку (по желанию — в подпапку категории); «Переместить…» для любого торрента — с прогрессом в колонке «Статус», свободным местом на диске и выбором, что делать с уже лежащими там файлами
- пропавшие файлы (диск отключён, папка переименована): торрент останавливается со статусом «Нет файлов» вместо тихой перекачки с нуля; «Указать расположение файлов…» — найти их на новом месте с проверкой
- правка трекеров торрента и «Заменить в трекерах…» — например, сменить passkey во всех торрентах без перекачки
- импорт из qBittorrent (с прогрессом, без перепроверки, с категориями) и BitComet (с перепроверкой файлов) — кнопка в шапке
- «Сохранить .torrent…» (Ctrl+E) для выбранных торрентов — с текущими трекерами (passkey), комментарием и датой, тот же хеш (v1, v2, гибрид); автокопирование .torrent добавленных и скачанных торрентов в свои папки
- резервная копия одним .zip (настройки, торренты, история, статистика, баны) и восстановление на другом ПК — с заменой папок (другая буква диска), прежнее состояние откладывается в before_restore_…
- привязка к сетевому интерфейсу (VPN kill-switch): если адаптер пропал — весь трафик блокируется, в шапке красное предупреждение
- шифрование соединений: предпочитать / только шифрованные / выключить
- IP-фильтр: eMule ipfilter.dat, PeerGuardian .p2p, CIDR; файл или URL, .gz / .zip, обновление раз в неделю
- страна пира с флагом на вкладке «Пиры» и сводка «пиры по странам» (там же и на вкладке «Статистика») — IP Geolocation by [DB-IP](https://db-ip.com) (CC BY 4.0), база скачивается раз в месяц; флаги — [flag-icons](https://github.com/lipis/flag-icons) (MIT)
- автообновление: проверка GitHub Releases каждые 6 часов, уведомление с кнопкой «Скачать и установить» — тихая установка и перезапуск
- создание торрента: несколько трекеров, размер куска, формат v1 / гибрид / v2, веб-сиды, source-метка, прогресс хеширования
- проверка перед созданием торрента: файлы, размер, число кусков и размер .torrent, рекомендуемый размер куска, лишние файлы (Thumbs.db, desktop.ini, .DS_Store, __MACOSX…) с исключением одной галочкой, пустые файлы и папки
- меню трея: лимиты загрузки и отдачи в один клик, «Остановить все» / «Запустить все»
- боковая панель фильтров как в qBittorrent (Ctrl+B): статусы (загружаются, раздаются, завершённые, активные, застрявшие, нет файлов…), категории, теги, трекеры — со счётчиками; правый клик — запустить / остановить всю группу; поиск по названию или хешу
- старт / пауза / удаление (с файлами или без), проверка файлов (и у остановленных торрентов — они остаются остановленными), обновление трекера
- вкладки «Общее» (сводка как в BitComet: хеши v1/v2, части, кем создан…), «Пиры», «Трекеры», «Журнал»
- «Ошибка трекера»: торрент, который трекер отклоняет, виден в фильтре «Ошибки» (отказ только по v2-хешу гибрида ошибкой не считается)
- правила трекеров: защита от Hit & Run (мин. часов / рейтинг — не остановится по правилу раздачи, спросит перед удалением), общий лимит скорости на трекер
- кросс-сид: если файлы торрента уже есть в другом торренте (имена могут отличаться) — раздача без скачивания; пока данные не проверены, загрузка выключена, чужие файлы не портятся
- блокировка качалок (Xunlei, QQ, Baidu…) и пиров с фальшивым прогрессом, ручной бан с вкладки «Пиры»
- теги: несколько на торрент, колонка, фильтр, правый клик → «Теги…»
- питание: Windows не засыпает во время загрузки; «Когда всё скачается» в трее — сон, гибернация или выключение с отсчётом 60 с
- прогресс загрузок на кнопке в панели задач, скорость в заголовке окна; плавающий мини-виджет скорости поверх окон
- по завершении торрента: открыть папку и/или запустить программу (%N, %F, %D, %H, %L) — например, проверку антивирусом
- пауза загрузок при нехватке места на диске и продолжение, когда место освободилось
- статистика по трекерам: отдано, скачано и рейтинг на каждом трекере за всё время
- окно «Статистика» (Ctrl+I): скачано / отдано и рейтинг за всё время, время работы, запуски, рекорды скорости, добавлено и скачано торрентов, потери; график трафика по дням (7 / 30 / 90 дней) и по месяцам
- окно добавления спрашивает трекер (scrape, HTTP и UDP): сколько сидов и личеров, живая ли раздача
- если файлы торрента уже лежат в папке — вопрос: проверить и докачать или раздавать без проверки
- создание приватного торрента для заливки на трекер, с раздачей сразу
- лимиты скорости, порт, очередь, UPnP; трей и уведомления о готовой закачке
- автозапуск с Windows (свёрнутым в трей), одна копия программы
- RU / EN: переключатель в шапке (и в настройках), клиент сам перезапускается на новом языке; при первом запуске — язык установщика
- сессия: %APPDATA%\ArtCoreClient (сохраняется при переустановке); портативный режим — `portable.ini` рядом с exe, всё в папке `Data` (portable-архив уже так настроен)

Клиент честно представляется трекерам:
- peer_id: `-Ag1000-` + 12 случайных символов
- User-Agent: `ArtCore/1.0.0 libtorrent/<версия>`

## Скачать
Готовый установщик — в [Releases](https://github.com/Ruf790/artcore-torrent-client/releases).
Сборки каждого коммита — во вкладке Actions (Artifacts).

## Сборка (Windows)
1. Python 3.12 или 3.13, 64-bit, с python.org (галочка «Add to PATH»)
2. Inno Setup 6.3+ с jrsoftware.org
3. Запустить `build.bat`

Результат:
- `dist\ArtCoreClient\ArtCoreClient.exe` — портативная версия (папка целиком)
- `installer\ArtCoreClient-Setup-1.0.0.exe` — установщик

## Установщик
- установка «только для меня» без прав администратора, или «для всех»
- задачи: ярлык на рабочем столе, .torrent, magnet, автозапуск,
  правило брандмауэра (только при установке «для всех»)
- клиент регистрируется в «Параметры → Приложения → Приложения по умолчанию».
  Если раньше .torrent открывал другой клиент, Windows 10/11 сам не отдаст
  ассоциацию — выберите ArtCore Client в «Приложения по умолчанию» или
  при первом открытии .torrent-файла.
- обновление: просто поставить новый установщик поверх (клиент закроется сам)

## Запуск из исходников
```
pip install -r requirements.txt
python run.py
```

## Новая версия
Поменять номер в трёх местах и смерджить в `main`, затем на GitHub:
**Releases → Draft a new release → тег `v1.1.0` → Publish release** —
GitHub Actions сам соберёт установщик и прикрепит его к релизу (≈3 мин),
а установленные клиенты предложат обновиться:
- `artcore/__init__.py`: `VERSION`, `VERSION_TUPLE` (peer_id берёт только мажор и минор: 1.0.x → `-Ag1000-`, 1.1.x → `-Ag1100-`)
- `setup.iss`: `#define AppVersion`
- `version_info.txt`: filevers / prodvers / FileVersion / ProductVersion

## Настройка трекера
- `admin/allagents.php`: добавить `-Ag1000-` в allowed_clients (если включён bannedclientdetect);
  новый префикс нужен только при смене минорной версии (1.1.0 → `-Ag1100-`), исправления 1.0.x его не меняют.
- `include/functions_getagent.php`: клиент уже в базе.

## Другие трекеры
Клиент работает с любыми трекерами, DHT и magnet-ссылками.
Приватные трекеры с белым списком клиентов пропустят его, только когда
его туда добавят их админы. Подмены peer_id под другие клиенты в нём нет
и не будет: за это на приватных трекерах банят.
